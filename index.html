1 なぜ作ったか

AIで訳せても、英単語は身につかない。

AIで仕事のスピードは爆発的に上がった。英文メールはすぐに訳してくれるし、返信案も英語で作ってくれる。英語を使ったコミュニケーションは、確かに進んでいる。

けれど、自分に「残った英語」がないことに、気がついた。

My Tango Note は
英語をあなたに残す単語ノートです。

1単語ずつ、ちゃんと残していく。

気になった英単語をClaudeに尋ねると、その意味・例文・ニュアンスが、英語と日本語の両方で整えられて返ってきます。

集めたエントリーは、検索・フィルタ・読み上げに対応。CSVやJSONでいつでも書き出せるので、あなたの言葉は、ずっとあなたのもとに。

サーバーなし、アカウントなし、ログインなし。ブラウザ1つで動く、あなただけの単語ノートです。

transparency/trænsˈpærənsi/
noun 💼 Business
Meaning
EN
The quality of being open and accountable — sharing information so decisions can be clearly seen.
JP
情報や意思決定のプロセスを隠さず開示する性質。組織運営や政治の文脈では「説明責任を伴う開示」というニュアンス。
Example
EN
The new leadership has prioritized transparency — they share weekly updates on company performance.
JP
新しい経営陣は透明性を最優先にしている。業績の数字も含めて、週次で全社に共有している。
3 4つのモード

同じ単語でも、あなたの文脈で例文が変わる。

ビジネスで使う "conflict" と、文学で語られる "conflict" は、同じ言葉でもまるで別もの。あなたの読む文脈、書く文脈に合わせて、Claudeが例文と注釈を整えます。

4 始め方

3つのステップで、今日から始められる。

1
ノートをダウンロード
GitHub から ZIP を一括ダウンロード、もしくは index.html を個別保存。ダブルクリックで開けば、それがあなたの単語ノートです。同梱の examples.html は完成イメージの見本として参考になります。サーバー不要、すべてローカルで完結します。
💡 ダウンロードした index.html をブラウザで開いたら、お気に入り(ブックマーク)に登録しておくと便利です。いつでも 1 クリックで自分のノートに戻れます。
GitHub → Code → Download ZIP
2
AI に、最初のメッセージを送る
GitHub の README にある「スタータープロンプト」を、お使いの AI(Claude / ChatGPT / Gemini)にコピペするだけ。これで、英単語を尋ねるたびに、整えられたエントリーが返ってくるようになります。
「My Tango Note の準備ができました」と返ってきたら、準備完了
3
単語を尋ねて、ノートに加えていく
気になった英単語を AI に尋ね、返ってきた塊をノートの「単語を追加」エリアに貼り付け。追加 → ボタンひとつで、エントリーが整って並びます。追加した内容は自動で保存され、いつでも HTML としてダウンロードして手元に残せます。
コピー → 貼り付け → 追加 →エントリー完成
